Le jeu de déduction

Code secret
en couleurs

Quatre couleurs. Dix essais. À vous de percer le secret.

Comment jouer ?

Retrouvez les quatre couleurs dans le bon ordre. Une couleur peut apparaître plusieurs fois.

  • Bien placée : la couleur est à la bonne position.
  • Mal placée : la couleur est présente ailleurs dans le secret.

Chaque occurrence compte une seule fois. Les indices ne désignent pas de position précise.
